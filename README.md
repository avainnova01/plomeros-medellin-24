# Plomeros Medellín 24 - Sitio Web Oficial

Sitio web moderno, responsive y optimizado para **Plomeros Medellín 24**, servicio de plomería profesional a domicilio 24 horas en Medellín y el Área Metropolitana.

## 🚀 Características
- **Diseño Moderno & Responsive**: Totalmente adaptado a móviles, tablets y computadores de escritorio.
- **Optimización WebP**: Imágenes de alta resolución comprimidas en formato `.webp` para máxima velocidad de carga.
- **Llamadas & WhatsApp Directo**: Botones para llamada inmediata (+57 302 227 4397) y chat de WhatsApp con mensajes personalizados por servicio.
- **Redes Sociales Integradas**:
  - Instagram: [@plome_romedellin](https://www.instagram.com/plome_romedellin)
  - TikTok: [@juanurrego91](https://www.tiktok.com/@juanurrego91)
- **Catálogo de 10+ Servicios Especializados**:
  - Destapamiento sin romper (sondas eléctricas)
  - Servicio de geófono digital (detección de fugas no visibles)
  - Reparación de fugas de agua y gas
  - Mantenimiento e instalación de calentadores
  - Instalación de lavamanos, lavaplatos, sanitarios y grifería
  - Reparación de humedades

## 🛠️ Tecnologías
- HTML5 Semántico
- CSS3 Moderno (Vanilla CSS con CSS Custom Properties, Flexbox & CSS Grid)
- JavaScript Vanilla
- Font Awesome 6 & Google Fonts (Outfit)
